Какие данные использует приложение

Версия 0.3.0 не содержит регистрации, рекламы, аналитики или сетевых функций, не запрашивает разрешения Android и не собирает персональные либо технические данные пользователя.

Локальное хранение

Игровой прогресс, рекорды и история показанных вопросов сохраняются только в закрытом хранилище приложения на устройстве. Эти сведения не передаются разработчику или третьим лицам. Облачное резервное копирование приложением отключено.

Удаление и срок хранения

Локальные данные хранятся до очистки хранилища приложения в настройках Android или удаления приложения. Аккаунтов и серверной копии данных нет, поэтому отдельный запрос на удаление не требуется.

Сайт

Страница политики размещается на GitHub Pages. При посещении сайта GitHub может обрабатывать технические сведения сетевого запроса согласно собственной политике. На странице нет форм, рекламы, аналитических счётчиков или собственных файлов cookie.

Изменения

Перед добавлением рекламы, аналитики, сетевых функций или иных способов обработки данных эта политика и декларации магазинов будут обновлены. Актуальная первая версия приложения не содержит рекламных SDK.
